A one-image summary of the world's news of **Thursday 19 November 2026**,
drawn by a deterministic Python program (`main.py`, Pillow only, no network).
Run it and it writes `entry.png` (1024×1024 PNG): a newspaper front page
with the day's six biggest stories.

## The six stories

1. **Trump, Xi and Putin hold first three-way summit** — the leaders of the
   US, China and Russia meet in Shenzhen on the APEC sidelines, the first
   talks of the three together. (Reuters)
2. **Iran fires drones at US bases in Kuwait and Bahrain** — overnight
   strikes follow a US attack on a missile site on Iran's Qeshm Island;
   Gulf defences intercepted the drones. (Reuters)
3. **Anthropic starts trading after record $81.3bn IPO** — shares debut on
   Nasdaq as ANT at $83, valuing the Claude maker at about $1.5 trillion,
   a record IPO. (Bloomberg)
4. **Crimean Bridge hit for a third time in a week** — an overnight strike
   halts traffic again, days after a 227-metre road section fell into the
   Kerch Strait. (Deutsche Welle)
5. **World court to rule today on Rohingya genocide case** — the ICJ in
   The Hague delivers its verdict on whether Myanmar committed genocide,
   a first for a state. (Human Rights Watch)
6. **EU proposes €45bn loan for Ukraine** — Brussels would lend Kyiv up
   to €45 billion for 2027, to be repaid only if Russia pays war
   reparations. (Reuters)

## How to run it

```sh
python3 main.py            # writes ./entry.png
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

No network, no randomness, no timestamps: two runs write byte-identical
PNGs.
